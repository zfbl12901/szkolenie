# Module 1 — Query Optimization

## 🎯 Objectives
- Understand how PostgreSQL actually executes a query.
- Diagnose and optimize SQL performance on large volumes.
- Learn to use execution plans to identify bottlenecks.

---

## 📋 Prerequisites

Before starting this module, you must master:

- **Basic SQL** : SELECT, WHERE, JOIN, GROUP BY, ORDER BY
- **PostgreSQL fundamentals** : connecting to a database, creating tables, inserting data
- **Database concepts** : tables, columns, indexes, primary/foreign keys
- **Environment** : access to a PostgreSQL instance (local or remote) and the `psql` tool

**Recommended level :** Intermediate (at least 6 months of SQL experience)

If you are new to PostgreSQL, first consult the basics: table creation, simple queries, basic index management.

## 📚 Content

### 1. EXPLAIN / EXPLAIN ANALYZE

PostgreSQL provides two essential commands to understand and optimize query performance: **EXPLAIN** and **EXPLAIN ANALYZE**.

---

#### 1.1 EXPLAIN

- **Objective** : see the **estimated execution plan** by the PostgreSQL planner **without executing the query**.  
- Useful for analyzing the estimated cost of a query and anticipating bottlenecks before it touches large volumes of data.
